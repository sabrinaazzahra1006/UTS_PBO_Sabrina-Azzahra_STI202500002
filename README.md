# UTS PBO Sabrina Azzahra STI202500002
## Deskripsi
Proyek ini merupakan tugas UTS Pemrograman Berorientasi Objek (PBO) yang mengimplementasikan struktur data Stack dengan konsep LIFO (Last In First Out) untuk perhitungan gaji karyawan + log sensor absensi.
Program membaca data karyawan dari `employee.json` dan memproses dari stack (LIFO), lalu menghitung bonus beserta total gaji.
## Struktur File
- `employee.json` — Berisi data master karyawan (ID, Nama, Jabatan, Gaji Pokok)
- `main.py` — Program utama Python untuk menjalankan sistem PBO dengan Stack LIFO
- `sensor_logs.json` — Berisi log sensor/absensi karyawan untuk perhitungan bonus
- `README.md` — Dokumentasi proyek ini
## Cara Menjalankan
```bash
python main.py
